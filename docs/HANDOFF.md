# Claude Code 전달 메모 — v0.2 업데이트

이전에 받은 `CLAUDE.md`, `docs/SITE_SPEC.md`(v0.1)를 이번 파일로 **덮어쓴다.** 새 파일 `docs/design-reference.html`이 추가됐다.

## 바뀐 것

1. **디자인 방향 확정**: 홈 첫 화면 A(다크 흐름선) · 본문 B(예시 UI 카드) · 모든 서브페이지 상단 C(컬러 블록 타이틀).
2. **디자인 기준 화면 추가**: `docs/design-reference.html` (`#home`, `#learn`, `#titles`). 레이아웃·간격·컴포넌트·모션은 이 파일 기준. 코드는 복사하지 말고 CLAUDE.md 구조·토큰으로 재구현.
3. **색 토큰 교체**: v0.1 팔레트 폐기. CLAUDE.md의 새 토큰 사용. 컬러 블록 전용 진한 톤(`--*-d`) 추가.
4. **웹 접근성 필수화**: KWCAG 2.2 / WCAG 2.1 AA. 본문 바로가기, 대비, 탭 ARIA 패턴, 정지 버튼, 예시 UI 카드 `role="img"` 처리 등. 페이지 완료 조건에 axe/Lighthouse 100점 포함.
5. **제품 스크린샷 미사용**: 제품은 HTML로 그린 예시 UI 카드 컴포넌트(`ui-card` 계열)로 표현. 규칙은 SITE_SPEC 2-0.
6. **모션 목록 교체**: M1~M12 새로 정의. 타이핑 효과는 예시 UI 카드 안에서만 허용.
7. **홈 구성 변경**: SITE_SPEC 2-1 (7개 섹션). Why Xinics는 About으로 이동.
8. **서브페이지 공통 구조**: SITE_SPEC 2-2.

## 작업 순서 (이미 진행한 단계가 있으면 그 위에 반영)

1. `css/tokens.css`를 새 토큰으로 교체. 기존 페이지에서 옛 토큰을 쓰는 곳 전부 치환하고 목록 보고.
2. 공통 컴포넌트: 본문 바로가기, 헤더(다크/라이트 전환), 푸터, 버튼, **서브페이지 타이틀 블록**, **ui-card 계열**, 탭(ARIA), 마퀴, 마지막 안내 블록, 요소별 정지 버튼(히어로·마퀴·탭 옆, 헤더에 두지 않음), reduced-motion 처리. `docs/components.html`에 모아서 확인.
3. `js/flow-canvas.js`: 홈 히어로·마지막 안내 블록 흐름선. 화면 밖이면 중지, reduced-motion이면 정지 프레임.
4. 홈 → Solutions 4페이지 → 나머지 서브페이지 순.
5. 각 단계마다 접근성 점검 결과(axe 오류 수, 키보드 순회 결과)와 TODO 목록 보고.

## 피드백 반영 (2026-11-17)

- 도입 문의·영업 리드 수집용 사이트가 아님 → "도입 문의/도입 상담 신청" 버튼, "소개서 받기" 링크 전부 제거. 헤더 Contact 는 일반 링크.
- 정지 버튼은 헤더가 아니라 움직이는 요소 옆(히어로 우하단·마퀴 끝·탭 아래).
- 4단계 탭: 클릭해도 자동 진행 유지.
- 로고는 이미지(`assets/logos/`). 원본 수급 전 임시 SVG.
- CTA 는 전부 콜아웃으로: 행동 유도 버튼 없이 정보만 (홈 히어로는 4영역 요약, 홈 끝은 회사 소개 콜아웃, Culture 끝은 채용 콜아웃). 사이트 목적은 회사 소개.
